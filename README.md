What does Succeed Reed do?:
----------------------------------------------------------------------------------------------------------------------------------------
SucceedReed is a website that helps users track their woodwind reeds. Reeds require proper resting time, tracking, and breaking in
in order to ensure that they do not die prematurely. Furthermore, this website calculates a health score based on the ratings the user
provides of the recent practice sessions to determine what reeds the user should be playing on.

Why is Succeed Reed helpful?:
---------------------------------------------------------------------------------------------------------------------------------------------
Oftentimes reeds are looked over and are improperly played because of the hassle, time, and money that can go into it.
This website aims to eliminate that hassle and to allow the user to keep their reeds in great condition without having to manually track it.
Also, many newer players play very few reeds, so this website makes it easy for them to rotate their reeds.
Professionals and beginners alike can use this tool to determine what reeds are best for performance and what reeds are best to break in.

How can you get started?:
----------------------------------------------------------------------------------------------------------------------------------------------
You can get started simply by creating a local website on your system. Add your first reed and your first session!

Where can I get help?:
--------------------------------------------------------------------------------------------------------------------------------------------------
Upon loading the site, there is a help button in the top-right corner. This help menu explains the formulas, terms, and proper usage of the site.
